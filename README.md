This project is a helpful calorie-counting tool that users can use to track meals, exercise, and net calorie intake.

Running it is simple; load the solution into Visual Studio, and use either a .NET Android emulator or a Windows machine to launch the app.
After that, you can add new meals or activities from the main page.
The calculated net calorie intake will automatically update as you add data.
User information is saved locally as JSON files.
